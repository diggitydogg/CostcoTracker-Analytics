# Cloud Task 03 — Dashboard and Item Explorer UI

Build the first useful dashboard using existing import and analytics layers.

Required screens:
- Overview
- Spending
- Items + item detail + price history
- Returns
- Adjustments

Overview should include gross spend, trips/orders, average basket, unique items, supported return metrics, actual recorded adjustment savings, monthly spend, repeat items, categories if available, warehouse vs online.

Drill-down requirement: cards/charts/aggregates must lead to the source transactions that produced the number.

Responsive:
- excellent desktop
- usable tablet
- no page overflow at 320px
- charts reflow
- local table scrolling only when needed
- touch targets around 44px

Accessibility:
- keyboard navigable
- meaningful labels
- chart summaries/tables where practical
- no color-only meaning

Constraints:
- no backend
- no telemetry
- no real data
- no duplicated analytics formulas in components
- no AI classification yet

Create a focused PR with tests/build and screenshots if available.
